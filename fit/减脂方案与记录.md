## 2. 两周试吃调整协议(核心方法)

**原理**:按好人松松经验配额吃 2 周, 用体重变化率校准碳水量。不直接算总热量, 只算每天碳蛋脂克数(4:4:9 折算仅用于记录对比)。

**记录要求**:
1. 每天晨起空腹(上完厕所后)称体重, 记晨重。
2. 每天记录三餐+加餐中每种食物的重量(g), 查表19营养率换算成 碳水/蛋白质/脂肪 克数。
3. 每日热量 = 碳水×4 + 蛋白质×4 + 脂肪×9 (kcal), 仅作记录, 不作执行依据。

**调整规则(碳水是唯一变量)**:
- 试吃 2 周, 体重减约 2%(当前 87.15kg → 约减 1.74kg)就不调整。
- 掉太慢 → 碳水减 0.5g/kg;掉太快 → 碳水加 0.5g/kg。
- 蛋白、脂肪配额固定不动。
- 体重降低 5-10kg 后重算一次配额;期间不用重算。

> 注意:单日体重波动(食糜+水分)可达 1-2 kg, 只看 1-2 周的比较。

## 3. 选用方案:表4《减脂-午饭后练》(中午主训练)

力训日餐序(4 餐+零食):

| 餐序 | 角色 | 要点 |
|---|---|---|
| ① 早饭 | 普通餐 | 蛋白:鸡蛋+牛奶 / 鸡蛋(数量参考视频 25:30);碳水按配额 |
| ② 午饭 | 练前餐 | **只垫碳水, 不吃蛋白质**:小馒头/香蕉(小20g大30g碳水)/脉动30g/可乐50g;五六分饱, 吃完就开练 |
| ③ 练后餐 | 全天最大一顿 | 练完 30 分钟内吃;先吃碳水和蛋白, 蔬菜少吃后吃(不压胰岛素);无正餐可用快碳+蛋白粉 |
| ④ 晚饭 | 其他餐 | 瘦肉(去皮禽肉/无白脂猪牛肉/鱼虾贝/肝肾肚血)+ 蔬菜 |
| ⑤ 零食/夜宵 | 抵扣项 | 不吃碳水食物和糖油混合物;可吃鸡蛋、无糖饮料等 |

晚上窗口:晚上还有 30min 力训, 练后有第二个碳水窗口 — 吃快碳水(白馒头 90g = 45g 碳水), 可搭蛋白粉;晚饭本身仍按"其他餐"(瘦肉+蔬菜)执行。

### 休息日(不力训 = 休息日, 与有氧无关)

3 餐+零食:① 早饭(同力训日早饭) ② 午饭 ③ 晚饭 ④ 零食/夜宵;蛋白来源同力训日, 碳水减少。

### 通用规则(力训日/休息日均适用)

- **瘦肉只有**:去皮的鸡鸭肉、无白色脂肪层的猪牛羊肉、鱼虾贝、肝肾肚血。鸡皮鸭皮、排骨、大排、肥牛肥羊、午餐肉、肉肠肉丸、糖醋里脊、锅包肉、炸鸡、烤肉都不是瘦肉。
- **不吃糖油混合物**:饼干、蛋糕、点心、油条、煎饼、手抓饼、花式面包、膨化食品等。
- **不吃吸油菜**:煎炒鸡蛋(含番茄炒蛋)、油烧茄子、干煸菜系。
- **蔬菜不限制**:先吃多吃蔬菜后吃碳水(练后餐相反);蔬菜不用定量。
- **水果要算碳水**:苹果/橙子/香蕉 20-30g 碳水/个;梨/蓝莓/猕猴桃 14%;柚子/桃/葡萄/菠萝 10%;西瓜/蜜瓜/草莓 7%。吃水果 10g 碳水 = 主食少吃 30g 熟米饭。
- **这些不是蔬菜**:红薯(20%)、土豆(18%)、玉米(18%)、山药(13%)、芋头(13%)是主食。
- **脂肪**:早饭蛋黄+牛奶 + 正餐带油瘦肉菜基本就够;若吃低油无油菜, 全天补 30g 坚果或 3 个全蛋或 1 盒全脂牛奶。
- **炒菜油估算标准(2026-08-17 定)**:午餐食堂 — 素菜 5g/份、荤菜 10g/份;晚餐外卖/炒菜 — 素菜 15-25g/份、荤菜 20-30g/份;卤味/凉拌/蒸煮 — 0-5g。外卖重油菜按上限估, 不低估。
- **有氧**(若需要):体重 80 kg 以上不做有氧;70-80 kg 先不做, 饿再加;70 kg 以下每周 2 小时。心率约 120/分钟。力训前不做;力训后不超过 30 分钟;不做饭后有氧。每加 100 kcal 有氧消耗可多吃 100 kcal 饮食。
- **力训**:保持肌肉需练 3-5 次/周;新手从健身房起步, 用三分化;减脂期热量缺口主要靠饮食, 不靠力训消耗。

## 4. 目标配额(好人松松经验法, 执行标准)

来源:视频 17-21 分钟经验化饮食配额表, 减脂期男档(BMI 25.7, 未触发 BMI>28 档), 单位 g/kg 体重(按 87.15kg 折算):

|  | 碳水 | 蛋白质 | 脂肪 |
|---|---|---|---|
| **力训日** | 218 - 261g (初期 2.5-3g/kg) | **131g** (1.5g/kg) | **70g** (0.8g/kg) |
| **休息日** | 174 - 218g (比训练日少 0.5g/kg) | **131g** | **70g** |

对应热量(仅参考, 不作执行依据):力训日约 2020-2200 kcal, 休息日约 1850-2020 kcal。

**执行要点**:
- 只配碳蛋脂克数, 不直接算总热量;每天记录 4:4:9 折算值用于对比。
- 碳水从区间下限(218g/174g)起步, 试吃 2 周按体重调整, ±0.5g/kg 步进。
- 体重降到 77kg 左右(BMI 23)或减重 5-10kg 后重算一次。

### 调整后餐单示例(力训日, 基于你 100% 固定的食物)

**固定项盘点**(鸡排按实际成分表: 每100g 蛋白14.8/脂肪7.3/碳水2):
卤牛肉100g(蛋白30) + 卤鸡腿1个(蛋白25) + 鸡排200g(蛋白29.6) = **蛋白85g、脂肪~21g、碳水4g**

- **蛋白粉 30g + 早餐3蛋 + 牛肉加到120g** 才能补到 131g: 85+22.5+18+6 = 131g ✓
- **碳水缺口 ~218g 全在可调部分**:早餐主食 + 练前加餐 + 练后餐 + 晚上练后馒头。
- **脂肪缺口**:靠鸡蛋 + 坚果 + 菜肴油(不喝牛奶, 乳糖不耐受)。
- **早餐减负**:卤牛肉挪到练后餐吃, 早餐只留主食+鸡蛋。

| 餐次 | 内容 | 碳水 | 蛋白 | 脂肪 |
|---|---|---|---|---|
| 早饭 | 红薯/土豆 300g + 全蛋 3个 | 54g | 18g | 15g |
| 午饭=练前餐 | 卤鸡腿(建议去皮) + 香蕉 1根 | 25g | 25g | 3g |
| 中午练后餐 | 米饭 250g + 卤牛肉 120g + 蔬菜(带油) | 75g | 36g | 15g |
| 晚饭 | 鸡排 200g + 蔬菜 + 玉米 1根 | 34g | 29.6g | 14.6g |
| 晚上练后窗口 | 白馒头 90g + 蛋白粉 30g | 45g | 22.5g | 0 |
| 加餐 | 坚果 30g | 0 | 0 | 17g |
| **合计** | | **233g** | **131g** | **65g** |

- 碳水 233g 在 218-261 区间内(含晚餐玉米 30g;去玉米则 203g, 略低于下限, 建议保留)。
- 蛋白 131g 已精确对齐目标。**鸡排蛋白率低(14.8%), 若换去皮烤鸡胸(25%)则 200g 有 50g 蛋白, 同样重量蛋白多 20g** — 不强制换, 但知道这个区别。
- 脂肪 65g 接近 70g;差 5g 随意, 菜油多一勺即满。
- 早餐 300g 主食仍吃不下就减到 200g, 差额给中午练后餐米饭 250→300g 补回。
- 玉米注意: 甜玉米碳水率 20%、糯玉米 35%, 早餐选甜玉米按 300g≈60g 碳水算。
- 休息日: 碳水减 0.5g/kg → 174-218g, 减量顺序: 先去掉晚餐玉米, 再练后餐米饭 250g→200g, 蛋白脂肪不变。
